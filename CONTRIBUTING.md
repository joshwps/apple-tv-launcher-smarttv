# 🤝 Como Contribuir

Obrigado pelo interesse em melhorar o Apple TV Launcher!

## 🐛 Encontrou um bug ou tem uma ideia?
1. Vá até a aba [Issues](https://github.com/joshwps/apple-tv-launcher-smarttv/issues).
2. Verifique se alguém já não reportou o mesmo problema.
3. Se não, abra uma nova Issue descrevendo o problema (de preferência com fotos da tela).

## 💻 Quer enviar código?
1. Faça um **Fork** deste repositório.
2. Crie uma branch para a sua modificação (`git checkout -b feature/minha-melhoria`).
3. Faça o commit das suas alterações (`git commit -m 'feat: adiciona minha melhoria'`).
4. Envie para o seu Fork (`git push origin feature/minha-melhoria`).
5. Abra um **Pull Request** explicando o que foi alterado.
